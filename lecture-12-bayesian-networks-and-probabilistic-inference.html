Bayesian networks: building a joint model and reasoning from evidence

An alarm tells you that something happened. It does not tell you which explanation is responsible. A probability model must account for the competing explanations, combine observations without counting them twice, and recognize when its own assumptions make an observation impossible.

Independent textbook development accompanying CS221 Lecture 12: Bayesian Networks I. Recording timestamps follow local machine transcription. The finite probability models, derivations, counterexamples, implementation design, and exercises are teaching constructions; primary research is attributed beside the supported claims.

1. The model must retain information needed by the question 00:05

A building alarm has sounded while its operator is away. An intrusion is one possible explanation; a vibration event is another. If a separate sensor confirms the vibration event, should the operator become more or less convinced that an intrusion occurred? Answering from intuition alone is unreliable because the alarm selected an unusual subset of possible situations.

A policy maps available information to an action. A value function summarizes the expected utility of an action and its continuation under specified dynamics and rewards. That summary need not retain the separate contributions of the dynamics, reward function, and observation process. Changing the reward can therefore require learning a new value function even when the environment's transition probabilities stay fixed.

A model of the environment retains more structure. If an action does not change the transition law when its reward changes, a planner can reuse that law and recompute the preferred policy. This is a conditional advantage, not a universal claim that model-based methods are cheaper or more accurate. Model estimation, planning, and misspecification can all consume resources or introduce errors.

The alarm problem asks a different question from the earlier control examples. We have observed an outcome and want to infer unobserved attributes of the situation. A joint distribution assigns probabilities to complete combinations of attributes. It can support many such questions without requiring a separate predictor for each combination of observed variables. Its probabilities describe the stipulated model; calling it the source of inference does not make it certified knowledge of the real building.

The opening case will retain three binary variables: burglary \(B\), earthquake \(E\), and alarm \(A\). A value of one means that the corresponding event occurs, and zero means it does not. The names follow the conventional alarm example. All probabilities below are deliberately stipulated, including the unrealistically frequent earthquake; the calculation concerns the model rather than an operational alarm policy.

2. Random variables, assignments, and named axes 04:50

A finite random variable takes values in a specified finite set. Capitals name variables; lowercase letters name particular values. For \(d\) variables \(X_1,\ldots,X_d\), let \(\mathcal X_i\) be the nonempty domain of \(X_i\). A complete assignment \(x=(x_1,\ldots,x_d)\) belongs to the Cartesian product \(\mathcal X_1\times\cdots\times\mathcal X_d\), the set of all combinations of domain values.

Write \(P(x)\) for the probability of a complete assignment. Valid probability mass is nonnegative and sums to one over all assignments. These two requirements are separate: a table of positive scores is not yet a probability distribution. Its entries are dimensionless numbers, and normalization determines their relative interpretation as probabilities.

\[P(x)\ge0,\qquad \sum_{x\in\mathcal X_1\times\cdots\times\mathcal X_d}P(x)=1.\]

Consider a preliminary weather model. Sunshine \(S\) and rain \(R\) both have domain \(\{0,1\}\). The four stipulated masses are \(P(0,0)=1/5\), \(P(0,1)=2/25\), \(P(1,0)=7/10\), and \(P(1,1)=1/50\). They sum to one. These assignments are mutually exclusive, and together they exhaust this model's possible weather states.

The same joint can be stored as a tensor of shape \((2,2)\), with semantic axis order \((S,R)\). An entry at row \(s\), column \(r\) is \(P(S=s,R=r)\). Transposing without updating the labels changes the question represented by an index. Because both axes have length two, an ordinary shape check cannot detect that mistake.

A table over \(d\) binary variables has \(2^d\) assignments. This is an exact storage count for the full table, not a theorem that every inference algorithm must construct it. Bayesian networks will provide a smaller representation when the specified dependencies allow one. First we need operations whose meanings remain clear regardless of representation.

3. Marginalization collapses distinctions we are not asking about 09:32

The probability of sunshine must include every possible rain value. Marginalization adds the probabilities of assignments that differ only in variables being removed. Those assignments are disjoint events, so addition is the relevant operation. Selecting one rain value would answer a different question.

\[P(S=s)=\sum_{r\in\{0,1\}}P(S=s,R=r).\]

For \(s=0\), the result is \(1/5+2/25=7/25\). For \(s=1\), it is \(7/10+1/50=18/25\). The output is a two-entry vector ordered by sunshine value, and its entries still sum to one. The rain axis disappeared because rain was summed out.

In named contraction notation, the operation is s r -> s: retain the sunshine index and reduce the rain index. This is a semantic description of a finite sum. It can be implemented by loops, a tensor library, or exact rational arithmetic. A library does not validate that the axis called s really represents sunshine.

Several variables can be marginalized at once. Finite sums can be rearranged, so summing rain and then another latent variable gives the same exact result as summing both together. Rounded floating-point additions may differ numerically with evaluation order. The mathematical equality therefore supplies an oracle for a finite teaching implementation without implying bitwise equality for every numerical backend.

Marginalization loses information. Knowing only \(P(S)\) does not recover whether sunshine and rain tend to occur together. Distinct joint tables can share the same sunshine marginal. The alarm task depends on precisely such relationships, so replacing the joint by a list of separate event frequencies would remove information needed later.

4. Conditioning selects evidence and then renormalizes 13:27

Suppose rain is observed, so \(R=1\). Conditioning keeps only assignments compatible with that observation. Their original masses are \(2/25\) and \(1/50\). These masses add to \(1/10\), the probability of rain. The selected slice is an unnormalized joint slice, not yet a conditional distribution.

A conditional probability on an event of positive probability divides selected mass by that event's probability. For the weather model this gives

\[P(S=s\mid R=1)=\frac{P(S=s,R=1)}{P(R=1)},\qquad P(R=1)=\sum_sP(S=s,R=1)=\frac1{10}.\]

The two conditional entries are therefore \(4/5\) and \(1/5\). Observing rain changes the model's sunshine probability from \(18/25\) to \(1/5\). No parameters were retrained. The new distribution follows by restricting and renormalizing the existing joint.

An indicator \(\mathbf1\{r=1\}\) is one when its condition holds and zero otherwise. Multiplying the joint by this indicator sets incompatible rows to zero. The named contraction s r, r -> s then combines selection and rain reduction. A second reduction computes the evidence mass, and division produces the conditional. Omitting division changes the output's total mass from one to the probability of the evidence.

When an event has probability zero, this finite definition cannot divide by it. An implementation must report impossible evidence explicitly rather than return an all-zero vector or silently guess a conditional. A zero denominator may reveal inconsistent observations, a deterministic assumption that is too strong, or a model that excludes real possibilities.

This chapter treats finite discrete domains. Conditioning a continuous variable on one exact observed value generally involves densities and regular conditional distributions; the observed point can have probability zero even when inference is meaningful. The finite ratio above should not be transferred to that setting by dividing two zero event probabilities.

5. A query specifies what is observed, requested, and hidden 20:57

Let \(\mathcal Q\) be an ordered list of query variables, \(\mathcal O\) an ordered list of observed variables, and \(\mathcal L\) the remaining latent variables. These lists are disjoint and cover the model's variables. Their corresponding value assignments are \(q,o,\ell\). “Latent” here means unobserved for this query; a variable can be observed in a different query.

For fixed evidence \(o\), first form the query's unnormalized mass \(m_o(q)\) by summing the joint over every latent assignment. Let \(Z_o\) be the total selected mass, often called the evidence probability. The output contract is

\[m_o(q)=\sum_\ell P(q,o,\ell),\qquad Z_o=\sum_qm_o(q)=P(\mathcal O=o),\qquad P(\mathcal Q=q\mid\mathcal O=o)=\frac{m_o(q)}{Z_o},\quad Z_o>0.\]

The ordered query list matters: a table over \((B,E)\) has a different index interpretation from one over \((E,B)\). If evidence is empty, its event is the whole assignment space, so \(Z_o=1\). If the query is empty and the evidence is possible, the result is the single mass one on the empty assignment.

A database analogy is useful only at the level of operations. Evidence filters assignments, marginalization groups and adds them, and normalization creates a conditional distribution. Probability entries are model weights rather than a collection of verified physical records. Nor does the analogy make a query efficient: the explicit enumeration procedure may still visit an exponential number of assignments.

For traffic \(T\), season \(F\), sunshine \(S\), and rain \(R\), asking \(P(R\mid T=1,F=1)\) makes \(R\) the query, \((T,F)\) the evidence, and \(S\) latent. The sum over sunshine is mandatory even though sunshine is absent from the written question. Treating an omitted variable as zero invents an extra observation.

6. The alarm joint comes from one local distribution per node 24:10

Return to the opening alarm. Assume \(B\) and \(E\) are independent, each with probability \(1/20\) of value one. Independence means that their joint root probabilities multiply. Define \(A=B\lor E\), where \(\lor\) is logical OR. This child is deterministic: either root event triggers the alarm, and no other situation does.

The graph has edges \(B\to A\) and \(E\to A\). A parent of a node has an arrow into that node. For each variable, a local probability kernel specifies a normalized distribution over its values for each assignment of all its parents. A root has no parents and therefore has one ordinary probability row.

\[p_B(1)=p_E(1)=\frac1{20},\qquad p_B(0)=p_E(0)=\frac{19}{20},\qquad p_A(a\mid b,e)=\mathbf1\{a=b\lor e\}.\]

Lowercase \(p_i\) denotes a supplied local kernel; uppercase \(P\) denotes the joint or probabilities derived from it. This distinction tracks construction and derivation. It does not claim that they are unrelated probability objects. The alarm's joint is defined by multiplying the three node factors:

\[P(B=b,E=e,A=a)=p_B(b)p_E(e)p_A(a\mid b,e).\]

Only four of eight assignments have positive mass. The assignment \((0,0,0)\) has mass \(361/400\); \((1,0,1)\) and \((0,1,1)\) each have mass \(19/400\); \((1,1,1)\) has mass \(1/400\). Their total is one. Every assignment with an alarm inconsistent with the roots has zero mass.

There is one factor per node, including each root, not one factor per edge. The alarm factor depends on both parents together. Multiplying separate terms for “alarm given burglary” and “alarm given earthquake” would define a different expression and generally count alarm evidence twice.

The child table has semantic axes \((B,E,A)\) and shape \((2,2,2)\). Root tables have axes \(B\) and \(E\). The named product b, e, b e a -> b e a retains every assignment index. The graph determines the kernel scope \(p_A(a\mid b,e)\); reversing that expression to an earthquake kernel given burglary and alarm would disagree with this constructed graph.

7. Evidence can create dependence between independent roots 35:10

Before receiving an alarm, burglary has probability \(1/20\). Marginalizing earthquake and alarm from the joint recovers the root distribution. After an alarm, the relevant assignment masses are the three positive alarm rows. Their sum is \(39/400\). The burglary numerator includes both rows with \(B=1\), giving \(20/400\).

\[P(A=1)=\frac{39}{400},\qquad P(B=1\mid A=1)=\frac{20/400}{39/400}=\frac{20}{39}.\]

The conditional burglary probability is slightly above one half. This does not say that half of all situations contain burglaries: the alarm selected a rare subset. The two possible triggering events have equal root frequencies, and the situation where both occur belongs to both explanations.

Now observe an earthquake as well. Since \(E=1\) already guarantees \(A=1\), the alarm adds no restriction beyond the earthquake. The selected masses for \(B=0\) and \(B=1\) are \(19/400\) and \(1/400\). Their sum is \(1/20\), yielding

\[P(B=1\mid A=1,E=1)=\frac{1/400}{20/400}=\frac1{20}.\]

Earthquake has explained away the alarm in this model: the burglary posterior returns to its root probability. The reduction comes from the likelihood table and conditioning. It is consistent with prior independence because independence was asserted before selecting alarm situations.

Conditional independence would require \(P(B=1,E=1\mid A=1)\) to equal the product of the two conditional marginals. The joint value is \(1/39\), while that product is \((20/39)^2\). They differ. Indeed \(1/39\) is smaller, so the roots are negatively associated among alarm cases.

A local kernel is recoverable as an ordinary derived conditional only when its parent assignment has positive joint probability. For the alarm every root pair has positive mass, so this qualification causes no problem. In a model where a parent value is unreachable, a supplied normalized kernel row still contributes to the model specification but cannot be recovered by a zero-over-zero conditional calculation.

Observing \(E=1,A=0\) is impossible in the deterministic model. An inference routine must fail on that evidence. Replacing the OR kernel with a calibrated noisy alarm model could make the event possible, but that is a substantive model change; a numerical normalization trick cannot perform it.

8. A collider does not fix the direction of the evidence effect

The graph \(B\to A\leftarrow E\) is called a collider at \(A\): two arrows meet at the same child. Conditioning on the child can couple the roots. It does not, by itself, say whether learning \(E=1\) increases or decreases the probability of \(B=1\).

To isolate the missing assumption, take independent binary roots with positive probabilities for both values. Define \(q_{be}=P(A=1\mid B=b,E=e)\), with all four values positive. The conditional joint mass of the roots after \(A=1\) is proportional to \(p_B(b)p_E(e)q_{be}\). In its odds ratio, root factors and the common normalizer cancel:

\[\frac{P(1,1\mid A=1)P(0,0\mid A=1)}{P(1,0\mid A=1)P(0,1\mid A=1)} =\frac{q_{11}q_{00}}{q_{10}q_{01}}.\]

The left side compares the product of concordant conditional masses with the product of discordant masses. A ratio below one gives negative binary association; a ratio above one gives positive association. This is seen directly by comparing \(P(B=1\mid A=1,E=1)\) and \(P(B=1\mid A=1,E=0)\): cross-multiplying their positive denominators yields the same product comparison.

Positive influence from each root is insufficient for a negative result. Take fair independent roots and likelihoods \(q_{00}=1/10\), \(q_{10}=q_{01}=1/5\), and \(q_{11}=99/100\). Changing either root from zero to one increases the alarm likelihood at either fixed value of the other root. Nevertheless the odds ratio is \(99/40\), above one.

\[P(B=1\mid A=1)=\frac{119}{149},\qquad P(B=1\mid A=1,E=1)=\frac{99}{119}.\]

The second value is larger: a strong interaction between the roots outweighs the substitution effect seen in the OR model. A posterior given only \(A=1\) is a positive weighted average of its versions given \(E=0\) and \(E=1\), so the sign relative to that average agrees with the association direction. Deterministic zero entries fall outside the strictly positive derivation. Direct mass comparisons remain valid, and a zero denominator must never be divided by. In the OR model, \(q_{00}=0\) makes the odds-ratio numerator zero while its denominator remains positive.

The useful general lesson is to derive the evidence effect from the joint, not to infer its numerical direction from arrow shape. A graph specifies factor scopes and associated independence structure. Actual kernel values determine the posterior magnitudes and can make an independence hold accidentally even where the graph allows dependence.

9. A second observation can support a competing explanation 47:31

A four-variable teaching model makes the same mechanism less direct. Let \(C\) indicate a cold, \(D\) allergies, \(H\) a cough, and \(I\) itchy eyes. Every variable is binary. We use \(D\) for allergies to avoid reusing the alarm variable \(A\). These labels and probabilities describe a stipulated exercise, not a clinical model or medical recommendation.

Assume independent roots \(P(C=1)=1/10\) and \(P(D=1)=1/5\). Let the cough likelihood be \(9/10\) if \(c\lor d=1\) and \(1/10\) otherwise. Let itchy eyes have likelihood \(9/10\) when \(d=1\) and \(1/10\) when \(d=0\). The graph is \(C\to H\leftarrow D\to I\), and the joint is

\[P(c,d,h,i)=p_C(c)p_D(d)p_H(h\mid c,d)p_I(i\mid d).\]

When only cough is observed, sum out itchy eyes first. Each itchy-eye kernel row sums to one, so it disappears. If a cold is present, cough has probability \(9/10\) regardless of allergies, giving \(P(C=1,H=1)=9/100\). If no cold is present, cough has probability \((1/5)(9/10)+(4/5)(1/10)=13/50\), giving joint mass \((9/10)(13/50)=117/500\).

\[P(H=1)=\frac9{100}+\frac{117}{500}=\frac{81}{250},\qquad P(C=1\mid H=1)=\frac{9/100}{81/250}=\frac5{18}.\]

Adding itchy eyes changes the sum over allergies. Its marginal likelihood is \((1/5)(9/10)+(4/5)(1/10)=13/50\). With a cold present, the combined cough-and-itchy numerator is therefore \((1/10)(9/10)(13/50)=117/5000\). With no cold, separate the allergy rows: the combined numerator is \((9/10)[(1/5)(9/10)^2+(4/5)(1/10)^2]=153/1000\).

\[P(H=1,I=1)=\frac{441}{2500},\qquad P(C=1\mid H=1,I=1)=\frac{117/5000}{441/2500}=\frac{13}{98}.\]

Itchy eyes support the allergy explanation, which competes with a cold in explaining cough. There is no arrow from itchy eyes to cough. Evidence influences an inference by constraining the joint, not by requiring a direct edge from each observation to the requested variable.

The reduction from \(5/18\) to \(13/98\) depends on these likelihoods and independence assumptions. It cannot be converted into an inference about a reader's symptoms. Calibration of real frequencies, alternative causes, measurement definitions, and population selection would all need separate evidence.

10. Acyclicity makes normalized local kernels a normalized joint 58:05

A directed acyclic graph, abbreviated DAG, has directed edges and no directed cycle. A topological order lists its nodes so every parent appears before its child. Let the finite variables \(X_1,\ldots,X_d\) be numbered in such an order, and let \(\operatorname{pa}(i)\) be the parent indices of node \(i\). Supply a nonnegative normalized kernel \(p_i(x_i\mid x_{\operatorname{pa}(i)})\) for every parent assignment.

The Bayesian-network construction defines \(P(x)=\prod_{i=1}^d p_i(x_i\mid x_{\operatorname{pa}(i)})\). David Heckerman's tutorial, PDF pages 12–13, relates this factorization to conditional-independence assertions and the probability chain rule. There are two distinct uses: constructing a joint from kernels, and representing an already specified joint using its conditional independences.

Normalization. Under the finite-domain, DAG, and normalized-kernel assumptions above, the constructed \(P\) is nonnegative and sums to one.

Nonnegativity follows from multiplying nonnegative entries. In the final node of a topological order, \(X_d\) cannot be a parent of an earlier node. Its value therefore occurs only in its own remaining factor. Sum over \(x_d\); the row normalization gives one for every fixed earlier assignment. Remove that factor and repeat with \(X_{d-1}\). After all variables have been removed, the sum is one. The hinge is the reverse order: a variable's descendant factors have disappeared before it is summed out.

The same removal argument gives the marginal distribution of an initial segment of the topological order as the product of its kernels. At a positive-probability assignment of preceding variables, taking a conditional ratio then gives the next node's supplied kernel. Summing over earlier nonparents with fixed parents yields the same row when the parent assignment has positive probability. Unreachable parent rows have no derived conditional ratio, even though the construction requires a normalized row there.

Acyclicity is necessary for this normalization argument. With binary variables \(X,Y\), set \(p_X(x\mid y)=\mathbf1\{x=y\}\) and \(p_Y(y\mid x)=\mathbf1\{y=x\}\). Each row is normalized, but the cyclic product assigns mass one to both \((0,0)\) and \((1,1)\), for total two. Dividing by two would define a joint, but it would be an extra global normalization operation, outside the Bayesian-network construction just proved.

For binary nodes with at most \(k\) parents, a local table needs at most \(2^k\) free probabilities, one for each parent row. The full network therefore needs at most \(d2^k\) such numbers, compared with \(2^d-1\) free masses in an unrestricted binary joint. This counts representation parameters under a parent bound. It does not establish that every posterior is cheap to compute.

If the joint is known first, the chain rule factors it along any variable order into conditionals on all preceding variables, with arbitrary normalized extensions on unreachable histories. Replacing a full history by just the parents requires the corresponding conditional independence. Drawing fewer arrows without that property silently changes the joint. Conversely, drawing every preceding variable as a parent preserves a general joint but sacrifices compactness.

11. An autoregressive model defines a joint; inversion also needs a prior 1:00:44

For a fixed finite sequence length \(T\), let tokens \(X_1,\ldots,X_T\) take values in a finite vocabulary. A token is the discrete unit used by the text representation. An autoregressive model supplies a normalized next-token distribution conditional on preceding tokens. Its graph can give each position all preceding positions as parents:

\[P(x_1,\ldots,x_T)=\prod_{t=1}^T p_t(x_t\mid x_1,\ldots,x_{t-1}).\]

Sampling forward follows the topological order. An input prompt is treated as observed prefix evidence; the model then generates a continuation. Variable-length output requires an explicit end token or a termination mechanism. The fixed-horizon factorization alone does not prove that an unrestricted generation process terminates.

Inverse inference asks which prompt might have produced a specified response. Let \(U\) be a prompt from a finite set, \(V\) a response, \(\rho(u)\) the prompt prior, and \(L(v\mid u)\) a normalized response likelihood. If \(Z(v)=\sum_u\rho(u)L(v\mid u)>0\), the posterior is \(\rho(u)L(v\mid u)/Z(v)\). Maximizing likelihood alone drops the prior and generally answers a different question.

For an innocuous illustration, two prompts ask for a short or a detailed definition. Assign the short prompt prior \(9/10\) and the detailed prompt prior \(1/10\). A particular observed response has likelihood \(1/5\) under the short prompt and \(4/5\) under the detailed prompt. Evidence probability is \(13/50\), and the posterior prompt probabilities are \(9/13\) and \(4/13\). The higher-likelihood prompt is less probable after accounting for the prior.

Li and colleagues' 2025 investigator-agent paper, Section 2.1 and PDF pages 2–3, combines target-response log likelihood, investigator entropy, and prompt-prior log likelihood. These terms connect elicitation to variational posterior inference under particular coefficient choices. The following identity concerns finite distributions and does not reproduce their training pipeline or empirical results.

Let \(q(u)\) be a candidate distribution over prompts, supported only where \(\rho(u)L(v\mid u)>0\). Natural logarithms are denoted by \(\log\). Entropy is \(H(q)=-\sum_uq(u)\log q(u)\), with zero terms interpreted as zero. The Kullback–Leibler divergence from \(q\) to posterior \(\pi_v\) is \(D_{\mathrm{KL}}(q\Vert\pi_v)=\sum_uq(u)\log[q(u)/\pi_v(u)]\). Substituting \(\pi_v(u)=\rho(u)L(v\mid u)/Z(v)\) gives

\[\mathcal F(q)=\sum_uq(u)\log L(v\mid u)+H(q)+\sum_uq(u)\log\rho(u) =\log Z(v)-D_{\mathrm{KL}}(q\Vert\pi_v).\]

The substitution expands the logarithm into likelihood, prior, and evidence terms; the entropy contributes the negative log of \(q\). Divergence is nonnegative: applying \(\log z\le z-1\) to \(z=\pi_v(u)/q(u)\) on positive \(q\) support gives \(-D_{\mathrm{KL}}\le\sum_{q(u)>0}\pi_v(u)-1\le0\). Equality requires the posterior itself. Thus the unrestricted finite objective is maximized at \(q=\pi_v\). A restricted approximation family may not contain that distribution.

The paper's nearby use of “minimized” conflicts with the direction of its displayed objective under these coefficient choices. The identity determines the direction directly. Changing the entropy or prior coefficients changes the objective; a generic trained investigator should not be called an exact posterior sampler on the basis of this special-case identity.

12. An ancestral program samples the constructed joint 1:04:15

A probabilistic program uses random choices to produce an output. For a finite DAG, an ancestral sampler visits variables in topological order and draws each value from its kernel at the already sampled parent assignment. Random choices must be fresh and independent conditional on the inputs to each draw. The program must finish after the finite list of nodes.

In the alarm model, draw burglary from a Bernoulli distribution with success probability \(1/20\), independently draw earthquake from the same distribution, and set alarm to their OR. A Bernoulli distribution returns one with its success probability and zero otherwise. Multiplying the probabilities of the sequential draws produces exactly the earlier joint.

For the general network, the probability of generating a complete assignment is the product of its sequential sampling probabilities. At step \(i\), the conditional sampling law is the supplied \(p_i\) evaluated at that assignment's parents. Their product is the constructed \(P(x)\). This argument connects a program's random execution to a probability table; it does not require materializing the full table before sampling.

Reusing one random choice for both roots breaks the independence assumption. If both equal the same Bernoulli bit, burglary and earthquake occur together with probability \(1/20\), not \(1/400\), and the alarm probability becomes \(1/20\), not \(39/400\). A three-line program can therefore represent a very different joint while using individually correct root frequencies.

Arbitrary probabilistic programs can have loops, shared random state, dynamically created variables, or nontermination. They need an execution semantics beyond this finite-DAG proof. The finite construction is valuable because its distribution, termination, and dependency order can be inspected separately.

13. Rejection sampling estimates a conditional from accepted proposals 1:06:35

Suppose we can generate independent, identically distributed complete assignments from \(P\) but cannot cheaply compute a posterior. Rejection sampling draws proposals from the joint and keeps those satisfying the evidence event. A histogram of query values among the accepted proposals estimates the conditional.

Let \(N\) be a positive integer proposal count. For proposal \(j\), let \(I_j\) indicate that its evidence matches \(o\), and \(J_j(q)\) indicate that both its evidence matches and its query equals \(q\). The accepted count is \(K=\sum_{j=1}^N I_j\). When \(K>0\), the estimator is

\[\widehat P_N(q\mid o)=\frac{\sum_{j=1}^N J_j(q)}{K}.\]

If \(K=0\), no estimate exists. Returning an empty dictionary or an all-zero histogram conceals that failure; neither is a normalized conditional distribution. A useful return value reports proposed and accepted counts and represents the unavailable estimate explicitly. A category with zero observed count is also not proven impossible.

Let \(z=P(\mathcal O=o)>0\). Under the IID proposal assumption, the strong law of large numbers makes the numerator divided by \(N\) converge almost surely to \(P(\mathcal Q=q,\mathcal O=o)\), while \(K/N\) converges almost surely to \(z\). Since the limiting denominator is positive, their ratio converges to the conditional probability. The theorem concerns repeated random sampling as the count grows, not the accuracy of one seed or monotonic improvement of each realized run.

The number of accepts has binomial distribution: each proposal independently passes with probability \(z\). Consequently \(\mathbb E[K]=Nz\), and \(P(K=0)=(1-z)^N\). In the alarm model, \(z=39/400\), so one thousand proposals give expected accepted count \(97.5\), not a thousand posterior observations. For evidence probability \(1/1000\), one thousand proposals yield only one expected accept and roughly 37% probability of no accepts.

Condition on a positive accepted count \(K=k\). The accepted query values are IID draws from the posterior. For a binary query with posterior probability \(p\), the sample proportion has mean \(p\) and variance \(p(1-p)/k\le1/(4k)\). For an error threshold \(\epsilon>0\), the squared error is at least \(\epsilon^2\) on the error event, so its expected value gives

\[P(|\widehat p-p|\ge\epsilon\mid K=k)\le\min\left(1,\frac{1}{4k\epsilon^2}\right).\]

This is a conservative conditional bound. It supplies no estimate at zero accepts and does not describe model misspecification. With \(k=100\) and \(\epsilon=1/10\), the bound is \(1/4\); ten thousand proposals can still be insufficient if nearly all are rejected. Acceptance counts explain sampling efficiency more directly than raw proposal counts.

14. Future sensor evidence can inform an earlier hidden position 1:10:54

The symptom model can be sampled in parent order: cold, allergies, cough, then itchy eyes. Keeping proposals with cough gives a posterior over cold; adding itchy eyes changes the accepted set. Its exact values, \(5/18\) and \(13/98\), provide checks against which realized sampling error can be measured. A closer sample estimate in one run does not establish that its model is more clinically accurate.

A hidden Markov model instead organizes variables in time. Hidden position \(H_t\) depends on the previous position, and observed sensor value \(Y_t\) depends on the current position. Here \(t=1,\ldots,5\). These time-indexed positions replace the earlier cough variable \(H\); the domains and interpretation are different. We use \(Y_t\) for observations to avoid confusing them with the alarm's earthquake \(E\).

Set \(H_0=0\). Let movement bits \(Z_1,\ldots,Z_5\) and noise bits \(W_1,\ldots,W_5\) be ten independent fair Bernoulli variables. Define \(H_t=H_{t-1}+Z_t\) and \(Y_t=H_t+W_t\). The object either stays or moves one unit at each step; the sensor either reports its true position or one unit above it. These are stipulated dynamics, not a general tracking accuracy claim.

Ask \(P(H_3\mid Y_5=2)\). Evidence is in the future relative to the requested hidden state. Such inference is called smoothing. Filtering instead estimates a current state using observations available up to that time. Changing which observations are available changes the question even when the same joint model is used.

The event \(Y_5=2\) means \(Z_1+\cdots+Z_5+W_5=2\). The other four noise bits are unobserved and sum out. There are \(\binom62=15\) successful assignments of the six relevant fair bits, among \(2^6=64\), so the evidence probability is \(15/64\). Conditional on it, all choices of the two one-bit positions are equally likely.

The position \(H_3\) counts ones among the first three movement bits. If it is zero, choose both ones among the other three relevant bits, giving three assignments. If it is one, choose one position in each group of three, giving nine. If it is two, choose both positions in the first group, giving three. Thus

\[P(H_3=0,1,2\mid Y_5=2)=\left(\frac15,\frac35,\frac15\right).\]

Enumerating all ten-bit program executions gives the same result over 1,024 equally weighted paths; each relevant six-bit pattern occurs sixteen times because of the unobserved sensor noise. A program using zero-based lists reads position three at index two and observation five at index four. An off-by-one error could produce a normalized but incorrect posterior.

Before any observations, \(H_3\) has binomial probabilities \((1,3,3,1)/8\) over positions zero through three. The future sensor rules out position three and shifts the remaining masses. The backward reasoning changes our information about a previous state; it does not physically alter that state or demonstrate a causal effect of a future observation.

15. Missing observations, interpretability, and causality need distinct assumptions 1:14:17

A supplied joint can answer questions with different sets of observations. When itchy eyes are unrecorded, marginalize \(I\); do not interpret its absence as \(I=0\). This gives the cough-only query. When itchy eyes are recorded as present, condition on \(I=1\). The model offers a common representation for both inference tasks.

If the act of recording an observation carries information, however, it is an additional observed event. A clinician who records itchy eyes only in selected cases creates a missingness mechanism. Ignoring that mechanism is justified only under appropriate assumptions about how data were selected. Marginalizing a missing value in a given joint does not automatically solve learning from selectively missing data.

Named intermediate variables can make assumptions inspectable. The alarm graph exposes its two stipulated roots and its OR rule. That interpretability does not validate their frequencies or prove that all relevant causes were included. Adding a variable or changing a measurement definition can change the joint and its inferences.

Bayesian-network factorization alone also does not supply intervention semantics. Observing a variable means selecting situations where it takes a value. Physically setting it can change the mechanism that normally generates it. Two causal models can agree on an observational joint while disagreeing under intervention. Additional causal assumptions, evidence, and definitions are required before answering such questions.

The exact enumeration method has a transparent finite cost: visit each complete assignment and multiply its node factors, then aggregate selected query masses. It can become impractical as the assignment space grows. That is a property of this implementation design, not a proof that every query or every approximation is hard. The next chapter develops inference procedures that exploit structure and studies what their transition rules can and cannot reach.

16. An executable joint with an explicit failure contract

The original chapter program uses only the Python standard library. A Node contains a variable name, domain size, ordered parent names, and probability rows. Domain size \(k\) represents values \(0,\ldots,k-1\). Rows use lexicographic parent-axis order with the final value axis belonging to the child. A Network requires nodes in a supplied topological order; it rejects an unknown, later, or cyclic parent dependency rather than silently reorder the graph.

Kernel entries must be built-in integers or Fraction values in \([0,1]\), with numerator and denominator at most 128 bits. Floats and booleans are rejected. Each row must sum exactly to one. Nodes accept at most eight values and the network at most twelve nodes, subject to a total budget of 65,536 complete assignments. Each row's common sampling denominator must fit 256 bits. These explicit teaching bounds limit resources; they are not mathematical requirements of Bayesian networks.

The constructor copies parent lists and rows into immutable tuples. A joint call returns a fresh dictionary over every complete assignment, including zero-mass assignments. infer(query, evidence) takes an ordered query list and a dictionary of observed integer values, requires disjoint known variables, and returns the normalized query table together with its evidence mass. Zero evidence mass raises ValueError. Empty evidence and empty queries have the conventions defined in Section 5. Invalid names, shapes, probabilities, ordering, and budgets also raise ValueError.

A sample call consumes the caller's explicit Random stream. For a kernel row, it converts the rational entries to integer interval lengths using a common denominator, draws a uniform integer, and selects the interval containing it. This removes a floating-point threshold approximation from the teaching sampler. Python's seeded generator is a reproducible pseudorandom implementation, not a proof that deterministic seeded values are physically independent random draws.

reject owns a local seeded stream and reports proposals, accepts, every query category's count, and either an exact rational empirical histogram or None at zero accepts. Proposal count is a built-in integer from zero through 100,000, and seed is a built-in integer from zero through \(2^{32}-1\). Model helpers have no network or filesystem effects; returned objects are fresh, input specifications are preserved, and sampling's explicit random stream consumption is its permitted state effect.

17. Exercises and fully worked solutions

  1. For the weather joint, compute \(P(R)\), \(P(S\mid R=1)\), and \(P(R\mid S=1)\). State the retained and reduced semantic axes. Explain why the two conditionals differ.
  2. Derive all four positive alarm masses, the alarm probability, and the burglary posterior with and without earthquake evidence. Test conditional independence of the roots and diagnose evidence \(E=1,A=0\).
  3. For the positive-influence likelihood table in Section 8, compute both burglary posteriors and the conditional odds ratio. Determine the equality condition under which observing the other root does not change the posterior.
  4. Construct a normalized child kernel at an unreachable parent value, explain why it is not an observable conditional, and compare it with the cyclic equality example. Which assumption fails in each case?
  5. For evidence probability \(1/1000\), compute expected accepts and zero-accept probability after one thousand proposals. Derive a positive-count variance bound for a binary query and state what a run with no accepts can conclude.
  6. Derive the tracking posterior \(P(H_3\mid Y_5=2)\) by counting bit assignments. Compare it with the no-observation distribution of \(H_3\), specify zero-based array indices, and explain why the query is smoothing.
Solution 1 — Axis meaning is part of the probability query

Sum the sunshine rows while retaining the rain column index: \(P(R=0)=1/5+7/10=9/10\) and \(P(R=1)=2/25+1/50=1/10\). In named notation this is s r -> r. For \(P(S\mid R=1)\), select column one, retain sunshine, and divide \((2/25,1/50)\) by \(1/10\), obtaining \((4/5,1/5)\).

For the reverse query, select row \(S=1\). Its total mass is \(18/25\). Divide the two rain masses \(7/10\) and \(1/50\) by that total to obtain \((35/36,1/36)\). The numerator for simultaneous sunshine and rain is the same \(1/50\), but the evidence probabilities are different: \(1/10\) for rain and \(18/25\) for sunshine. Reversing the conditional changes both the output variable and denominator. Equal tensor dimensions do not make these operations interchangeable.

Solution 2 — Selection changes the relation between the roots

Independent root probabilities give \(361/400\) for neither event, \(19/400\) for each single event, and \(1/400\) for both. The deterministic child places these masses on alarms zero, one, one, and one respectively. Alarm probability is their latter sum \(39/400\). Burglary and alarm have joint mass \(20/400\), giving posterior \(20/39\).

Earthquake and alarm together have probability \(20/400\). Their burglary-positive row has mass \(1/400\), so the new posterior is \(1/20\). Root independence before evidence does not survive alarm selection: both-positive conditional mass \(1/39\) differs from \((20/39)^2=400/1521\). The stipulated OR rule assigns zero probability to \(E=1,A=0\), so conditioning on that pair is undefined. It calls for a model or observation investigation, not a made-up normalized answer.

Solution 3 — Interaction determines the association sign

Fair root priors contribute \(1/4\) to every row. The four alarm likelihoods sum to \(149/100\), so alarm mass is \(149/400\). Rows with \(B=1\) have likelihood total \(119/100\), giving joint mass \(119/400\) and posterior \(119/149\). Given \(E=1\), the burglary-positive likelihood is \(99/100\), while total likelihood across the two burglary rows is \(119/100\), giving \(99/119\).

The latter is larger because \(99\cdot149=14751\) exceeds \(119^2=14161\). The odds ratio is \((99/100)(1/10)/[(1/5)(1/5)]=99/40\). For strictly positive root priors and likelihood entries, equality of the two evidence-stratified burglary probabilities holds exactly when \(q_{11}q_{00}=q_{10}q_{01}\). The posterior given only alarm is their weighted average, so equality also means the added root observation does not change it. This condition is a statement about likelihood interaction, not merely positive influence along arrows.

Solution 4 — Unreachable rows and cycles are different boundaries

Let a binary root \(X\) satisfy \(P(X=0)=1\). Give binary child \(Y\) kernel probability \(p_Y(1\mid0)=1/3\) and \(p_Y(1\mid1)=3/4\), with complementary probabilities for zero. Every row is normalized and the graph \(X\to Y\) is acyclic, so the joint is valid. All assignments with \(X=1\) have zero mass. The row at \(X=1\) is supplied, but its purported derived conditional would divide zero by zero. The failed hypothesis is positive parent probability, not joint normalization.

In the cycle \(X\to Y\to X\), use deterministic equality in each kernel. The product is one on each equal pair and zero elsewhere, for total two. The failed hypothesis is acyclicity, even though every local row is valid. Renormalizing the product is a different construction. These examples explain why a validator must check both graph structure and the domain of each conditioning operation.

Solution 5 — Proposal count is not posterior sample count

Expected accepts are \(1000(1/1000)=1\). Independent proposal failures give \(P(K=0)=(999/1000)^{1000}\), approximately \(0.3677\). A zero-accept run is therefore ordinary under possible rare evidence. It cannot conclude that the evidence has zero model probability.

Conditioned on \(K=k>0\), the binary sample proportion averages \(k\) independent posterior Bernoulli draws. Each has variance \(p(1-p)\), so independence makes the mean's variance \(p(1-p)/k\le1/(4k)\). On absolute error at least \(\epsilon\), squared error is at least \(\epsilon^2\); comparing expectation with that event gives probability at most \(1/(4k\epsilon^2)\), capped at one. This bound requires a positive observed accepted count and valid IID proposal semantics. It does not turn the expected count one into an actual observation or assess the model's physical accuracy.

Solution 6 — A later observation constrains earlier possibilities

The last observation equals the sum of five movement bits and its own noise bit. There are fifteen two-one configurations among these six fair bits, so evidence mass is \(15/64\). Split them into the first three movement bits and the other three relevant bits. Earlier position zero has \(\binom32=3\) possibilities in the latter group; position one has \(3\cdot3=9\); position two has \(\binom32=3\) in the former group. Normalize by fifteen to obtain \((1/5,3/5,1/5)\). The other four noise bits marginalize out.

Without observations the first three movement bits give binomial masses \((1,3,3,1)/8\), including position three. Future evidence excludes that position under these nondecreasing dynamics and shifts the other weights. A zero-based program accesses \(H_3\) at index two and \(Y_5\) at index four. The use of time-five evidence to estimate a time-three state makes the query smoothing. Filtering at time three would require a specified set of observations available no later than time three and would be a different conditional.
