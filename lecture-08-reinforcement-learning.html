Reinforcement learning

Chapter 8 · Learn a route from feedback without confusing experience, value and optimum.

The commuter no longer knows tram reliability

A commuter must reach location 10 from location 1. Walking advances one location at a cost of one minute. A tram attempt costs two minutes and either doubles the location or fails and leaves it unchanged. Chapter 7 supplied the failure probability \(2/5\) and solved the route exactly. Now the commuter sees attempts and outcomes, but is not told that probability. After two failures and five successes at location 2, should the commuter behave as though failure probability were \(2/7\)? How much confidence should a policy learned from that small sample deserve?

This is a stipulated finite learning problem, not a measured transport system. The environment used for our checks retains the true failure probability \(2/5\); the learning algorithms receive only transition feedback. Separating those two views permits a meaningful check: a learner can optimize its estimated model while a held-out oracle evaluates the resulting policy in the true model. Agreement on one seeded run is evidence about that run, not a proof that learning has recovered every probability or the optimal policy.

The chapter follows the recording from model-based estimation through Monte Carlo returns, SARSA and Q-learning. It develops the missing conditions behind those mechanisms: what the state represents, what is sampled, what policy a return evaluates, when a terminal target is zero, and what asymptotic convergence requires. The persistent route links these questions; small additional examples isolate failure boundaries. All proofs, numerical fixtures and code are original teaching constructions. Source-grounded headings link the complete substantive recording sequence.

1. Preserve the MDP object while changing who knows it [00:05–06:04]

Let \(S=\{1,\ldots,10\}\) be the route's observed states. State 10 is terminal, with zero continuation reward and no action. At \(s<10\), walk is admissible; tram is admissible only if \(2s\le10\). Denote this state-specific set by \(A(s)\). The environment's distribution is \(P(s'\mid s,a)\), with nonnegative entries summing to one over next states. A walk gives reward \(-1\) and next state \(s+1\). A tram gives reward \(-2\) on both outcomes: next state \(s\) with probability \(p=2/5\), next state \(2s\) with probability \(1-p=3/5\).

A deterministic stationary policy \(\pi\) chooses \(\pi(s)\in A(s)\). A rollout records the actual states, actions and rewards generated by the policy and environment. If its rewards are \(R_1,R_2,\ldots\), its discounted return is \(G_0=\sum_{t\ge0}\gamma^tR_{t+1}\), stopping at arrival. Here \(\gamma\in[0,1]\) discounts per decision, not per elapsed minute. At \(\gamma=1\), maximizing this negative-minute return minimizes expected duration. At a smaller discount the criterion changes; a two-minute tram attempt still advances the exponent only once.

The route is proper for \(p<1\): every admissible action has a positive probability of progress, and there are finitely many locations to pass. Chapter 7 established finite expected completion time. Its undiscounted optimum walks to 5 and retries tram there, with value \(-22/3\), compared with \(-9\) for always walking and \(-12\) for tram-if-possible. These exact values are useful checks only if the same reward, action-mask and discount conventions are retained.

The recording's partial-application question concerns code organization: fixing the model argument of a two-argument function leaves a function of state. It does not alter the mathematical policy. More consequential is the information boundary. In model-based planning the agent receives the complete probability rows; in our learning problem the simulator holds them privately and emits one transition at a time. Inspecting the simulator's probability while calling an algorithm “model-free” would defeat the intended experiment.

2. An action value specifies its continuation policy [06:04–11:00]

The policy value is \(V^\pi(s)=\mathbb E_\pi[G_0\mid S_0=s]\). The action value \(Q^\pi(s,a)\) is the expected return after taking \(a\) once at \(s\), then following \(\pi\). Capital \(S_t,A_t,R_{t+1}\) denotes the random trajectory; lower-case \(s,a\) denotes a particular argument. For fixed policy and an integrable return, splitting off the first reward and conditioning on its successor gives

\[Q^\pi(s,a)=\sum_{s'}P(s'\mid s,a)[r(s,a,s')+\gamma V^\pi(s')],\qquad V^\pi(s)=Q^\pi(s,\pi(s)).\]

For a stochastic stationary policy, replace the latter expression by \(\sum_a\pi(a\mid s)Q^\pi(s,a)\). The transition reward \(r\) may be a conditional mean if the reward itself is random. The formula averages chance outcomes; the agent does not choose which successor occurs. When extracting a policy, \(\arg\max_{a\in A(s)}Q(s,a)\) selects an action, not a successor state.

The optimal values, \(V^*\) and \(Q^*\), use an optimal continuation rather than an arbitrary policy. Thus \(V^*(s)=\max_aQ^*(s,a)\) and \(Q^*(s,a)=\sum_{s'}P(s'\mid s,a)[r(s,a,s')+\gamma\max_{a'}Q^*(s',a')]\), with zero terminal continuation. The finite discounted conditions of Chapter 7 justify existence and a deterministic stationary optimum. Our tabular estimate \(Q_k\), after \(k\) updates, is neither of these true quantities merely because it is stored in a dictionary named Q.

The retained Sutton–Barto second-edition draft, PDF pp.84–85 and 89–91, defines policy and optimal action values and their distinct recurrences. Chapter 7 inspected these pages and backup diagrams; this chapter's additional algorithm boxes are checked separately. The draft is visibly an edition in progress with frontmatter copyright 2014, 2015, not an attested later edition.

3. Feedback is one observation, not a transition row [11:00–15:37]

An agent selects \(A_t\); the environment emits reward \(R_{t+1}\) and an observation. In the fully observed setting here, the observation identifies \(S_{t+1}\). The usable feedback record is \((S_t,A_t,R_{t+1},S_{t+1},D_{t+1})\), where the Boolean terminal flag \(D_{t+1}\) says whether the episode has ended. A failed tram sample at 2 is \((2,\text{tram},-2,2,\text{false})\). It does not reveal the probability of failure or the alternative successor that could have occurred.

The controlled Markov condition states that the next state/reward distribution, given current state and action, does not additionally depend on earlier history. This makes repeated feedback from a selected pair informative about a common underlying row. If reliability changes with hidden weather or breakdowns, location-only feedback need not satisfy that condition. An image observation is not automatically a sufficient state. A partially observed MDP, abbreviated POMDP, requires a further observation/latent-state model and often a state estimate or belief derived from history; the tabular guarantees below do not transfer by changing the word “state” to “image.”

Unknown transition probabilities motivate reinforcement learning in this lecture, but they are not its only possible motivation. Even with a known environment, explicitly planning across an enormous state space may be impractical, so sampled experience can train an approximation. The retained official TD module makes this separate computational motivation explicit. Its games material belongs to later lectures and is not additional coverage of this recording.

The speaker's comparison with learning from life is an attributed analogy, not a formal theorem about human decisions. Our task is narrower: infer useful values or a model from reward-bearing interactions under a declared finite environment. Exploration must reveal alternatives, and exploitation uses what has been learned. Trying an action can incur a cost; a method that eventually learns can still perform poorly or violate constraints during training.

4. Separate a fixed policy from an updating agent [15:37–24:38]

A learning agent has two operations: select an admissible action from the current observation, and incorporate feedback into its internal estimates. A static agent can implement the same interface while ignoring feedback and always following a supplied policy. This isolates the mechanism: interaction alone does not imply learning. Conversely, a policy can be explicitly time-dependent without being learned; “policy” and “agent” refer to different mathematical and computational roles, rather than universally static and dynamic objects.

The simulator performs one action selection, samples an outcome, reports the transition and advances the state. The reward on entering terminal is included; no terminal action is requested and no future reward is invented after arrival. A sparse-reward problem places informative rewards only on selected transitions, perhaps at the end. Sparse feedback can make credit assignment difficult, but absence of an intermediate reward does not mean the previous action has zero long-term value.

The feedback flag is operationally important. In the route, reaching 10 is an observed terminal event. A time-budget interruption while still at 5 is different: continuation may remain. Treating that interruption as arrival makes a partial episode look complete and changes its return. One can deliberately define a finite-horizon problem with terminal time, or bootstrap a truncated continuing trajectory under a declared convention. One cannot silently switch between those conventions.

The source demo averages returns while the agent updates. That number measures cumulative performance during learning under changing rules. It does not evaluate the frozen final policy. To estimate the latter, first freeze the learned table and action-selection rule, declare whether exploration remains enabled, then collect fresh episodes or evaluate in an independently known model. Our program's exact frozen-policy evaluation supplies the latter check for the stipulated route. It cannot validate the truth of an unknown real-world model.

5. Estimate counts and rewards, then plan [24:38–34:18]

The model-based approach has three stages: explore, estimate a transition/reward model, and plan/exploit in that estimated model. Uniform exploration at states with both actions chooses walk or tram with equal probability; where only walk is admissible it chooses walk. “Uniform” is over \(A(s)\), not a global list containing forbidden actions. This policy uses a known action catalogue while keeping probabilities unknown. Discovering the catalogue itself is a further problem discussed below.

Let \(N(s,a,s')\) count observed transitions from pair \((s,a)\) to successor \(s'\), and let \(N(s,a)=\sum_{s'}N(s,a,s')\). For positive \(N(s,a)\), the empirical probability is \(\widehat P(s'\mid s,a)=N(s,a,s')/N(s,a)\). If \(M(s,a,s')\) is the sum of rewards on those transitions, the conditional mean estimate, for positive successor count, is \(\widehat r(s,a,s')=M(s,a,s')/N(s,a,s')\). The expected immediate reward is then \(\widehat{\bar r}(s,a)=\sum_{s'}\widehat P(s'\mid s,a)\widehat r(s,a,s')\).

Both denominators have a role. Normalizing over every observation in the data set would mix different action rows. Dividing a reward sum by the total pair count rather than its successor count would estimate a probability-weighted contribution, not the conditional reward. The weighted conditional means nevertheless combine to the ordinary mean reward for that pair: substituting both ratios cancels the successor count, leaving \(\sum_{s'}M(s,a,s')/N(s,a)\). This identity is a useful implementation check.

The official executable lecture retains the latest reward for each transition triple. That is enough for its deterministic \(-1/-2\) rewards. It is not a conditional-mean estimator for stochastic rewards: observations 0 and 4 on the same triple have mean 2, while overwriting stores 4. Our original program retains exact reward sums of the binary64 observations and divides by the corresponding count.

An unobserved action has no empirical distribution. Declaring it impossible, or pretending it has probability-zero outcomes, restricts the estimated decision problem without evidence. Our finite implementation requires at least one sample from every admissible pair before planning and reports missing coverage explicitly. This is a minimal operational condition, not enough data to estimate a row accurately. Even after one sample, an unobserved successor can have positive true probability. Priors, confidence sets or optimistic models are possible alternatives, but their assumptions must be declared rather than hidden in a default value.

6. An estimated optimum belongs to the estimated model [34:18–42:12]

The recording observes two failures and five successes for tram at state 2 in a small batch. The empirical row is \(\widehat P(2\mid2,\text{tram})=2/7\), \(\widehat P(4\mid2,\text{tram})=5/7\). The true row in the simulator is \(2/5,3/5\). Both rows normalize to one; normalization alone does not establish accuracy. Their failure-probability difference is \(2/5-2/7=4/35\), and the row's total absolute probability difference is \(8/35\).

Value iteration in \((\widehat P,\widehat r)\) computes that estimated model's optimal value. It is not automatically \(V^*\) for \((P,r)\). To make the sensitivity precise, assume a finite common state/action catalogue, the same \(0\le\gamma<1\), normalized rows and expected immediate rewards bounded in magnitude by \(R_{\max}\) in both models. Define \(d_r=\max_{s,a}|\widehat{\bar r}(s,a)-\bar r(s,a)|\) and \(d_P=\max_{s,a}\sum_{s'}|\widehat P(s'\mid s,a)-P(s'\mid s,a)|\). These are deterministic model-error measures, not confidence bounds obtained from counts.

For any value array \(v\), the max-backup difference at a common state is at most \(d_r+\gamma d_P\|v\|_\infty\), by the max-difference inequality and triangle inequality. The true optimum obeys \(\|V^*\|_\infty\le R_{\max}/(1-\gamma)\). Compare the fixed points of the two operators, and use contraction of the estimated operator to absorb their value difference. This gives

\[\|\widehat V^*-V^*\|_\infty\le \frac{d_r+\gamma d_P R_{\max}/(1-\gamma)}{1-\gamma}.\]

The hinge is \(\|\widehat V^*-V^*\|\le\gamma\|\widehat V^*-V^*\|+d_r+\gamma d_PR_{\max}/(1-\gamma)\); the denominator appears only after moving the first term left. The same bound applies to the optimal action arrays: their difference is at most the model-backup error plus \(\gamma\) times the value difference. Thus model error can be amplified strongly near discount one. This original bound does not cover the undiscounted case by substituting \(\gamma=1\), and it does not itself turn seven observations into a statistical certificate.

Policy labels require another condition. If \(\|\widehat Q-Q^*\|_\infty\le\eta\) and a state has a unique best action with gap \(\Delta=Q^*(s,a_*)-\max_{a\ne a_*}Q^*(s,a)>2\eta\), its label is recovered: the estimated best action loses at most \(\eta\), a competitor gains at most \(\eta\), and the remaining gap stays positive. Without a gap, arbitrarily small errors can reverse an argmax. A one-step pair of rewards 0 and \(-\delta\) changes its preferred action if the second is estimated as \(+\delta\), for any \(\delta>0\). Close values and identical policies are different assertions.

The lecture reports a favorable estimated policy in one seed, another policy in a different seed, and a small exploitation sample mean around \(-6.6\). These are attributed finite demonstrations, not measured algorithm comparisons or exact policy values. The known undiscounted optimum is \(-22/3\approx-7.3333\); an observed sample mean can exceed an optimal expectation by chance. Such a sample neither disproves the optimum nor proves a learned policy better than it. Our separately seeded checks avoid reusing these figures as performance certification.

7. Coverage and observation boundaries are part of the algorithm [42:12–45:27]

Full observation means that feedback identifies the model state. It does not mean the agent already knows all states, actions or transition probabilities. The lecture acknowledges that a newly encountered state can be missing from a learned exploitation dictionary. Its inspected implementation has no fallback there. A complete agent must specify what happens: request admissible actions and explore, extend its representation, stop with an error, or use a declared fallback. Choosing a random label from an obsolete action list is not a valid solution.

Our teaching implementation takes a finite catalogue of states and admissible actions as input, treats empty rows as terminal, and rejects observations outside it. This narrower contract makes state–action coverage and terminal consistency checkable. It still learns probabilities and rewards from samples. A real system that discovers new states needs an additional catalogue/update protocol. The distinction is public so a successful fixed-catalogue test cannot be mistaken for open-world robustness.

Exploration and exploitation need not occur in separate phases. A model can be updated continuously and replanned periodically. But the estimates require repeated observations of relevant pairs. Trying actions only in frequently reached states can leave important downstream choices unmeasured. “More exploration” is not a proof of coverage unless the reachability and action-selection process are specified.

A useful counterexample is a two-stage route whose deeper state is reached only by two nongreedy choices. Suppose in episode \(j\) each such choice has probability \(\epsilon_j/2\), independently, with \(\epsilon_j=1/j\). The reach probability is \(1/(4j^2)\). The sum of these probabilities is finite, so the expected total number of deeper visits is finite; a nonnegative count with finite expectation cannot be infinite with positive probability. Deeper coverage is therefore finite almost surely, even though \(\sum_j\epsilon_j\) diverges. This is why a decaying exploration parameter alone cannot substitute for the state–action visitation hypothesis of a theorem.

8. Estimate action values from complete suffix returns [45:34–50:24]

A model-free method can store action-value estimates without estimating a generative transition distribution. For a complete episode ending after \(\tau\) transitions, its return from index \(t\) is \(G_t=\sum_{j=0}^{\tau-t-1}\gamma^jR_{t+j+1}\), with \(G_\tau=0\). Splitting its first term gives \(G_t=R_{t+1}+\gamma G_{t+1}\). A single backward pass therefore computes all suffix returns in time proportional to episode length, rather than separately summing each suffix.

In the source's artificial three-transition episode, walk from 1 to 2 gives \(-1\), a failed tram from 2 to 2 gives \(-2\), and a successful tram from 2 to 4 gives \(-2\). State 4 is deliberately treated as terminal for that feedback illustration; it is not terminal in the location-10 environment. At discount one the suffixes are \((-5,-4,-2)\). At discount \(1/2\) they are \((-5/2,-3,-2)\), obtained backwards from \(-2\), then \(-2+(1/2)(-2)=-3\), then \(-1+(1/2)(-3)=-5/2\).

For a fixed continuation policy \(\mu\), one complete return starting at a fixed pair \((s,a)\) has expectation \(Q^\mu(s,a)\). The behavior policy \(\mu\) is the rule producing experience. A target policy \(\pi\) is the rule whose values we want; in on-policy evaluation they agree. The conditioning and fixed-policy premise are essential. A return generated while future decisions explore does not evaluate a purely greedy continuation unless those rules happen to coincide.

The draft's PDF p.133 distinguishes action-value evaluation from the subsequent control problem and explains why state values alone do not select actions without a model. We use that mechanism, not its imprecise convergence-rate wording. Averaging returns bypasses transition estimation, but the environment's dynamics still determine those returns; “model-free” does not mean independent of the model that generates experience.

9. Epsilon-greedy and every-visit averages have different denominators [50:25–60:01]

Let \(Q_k\) be the current table and choose one greedy maximizer \(a_g(s)\) by a declared tie rule. Epsilon-greedy behavior with \(\epsilon\in[0,1]\) selects uniformly among all admissible actions with probability \(\epsilon\), and otherwise selects \(a_g\). With \(m=|A(s)|\),

\[\mu_k(a\mid s)=(1-\epsilon)\mathbf1\{a=a_g(s)\}+\epsilon/m.\]

The symbol \(\mathbf1\) is the indicator, one if its condition holds and zero otherwise. Exploration can select the greedy action too. With two actions and \(\epsilon=0.2\), their probabilities are 0.9 and 0.1, not 0.8 and 0.2. At \(\epsilon=1\) behavior is uniform; at zero it is greedy. A deterministic tie rule makes the exploitation component unambiguous but does not prove that a near tie in binary64 is an exact mathematical tie.

All admissible actions must participate in greedy selection. The official MC/SARSA implementations enumerate only observed action keys. If walking's observed estimate is \(-1\) and unobserved tram is assigned an initial estimate of zero, maximizing only observed keys chooses walk, while maximizing the declared complete table chooses tram. These are different exploration rules. Our table initializes every admissible pair to zero; optimism is explicit and cannot be confused with evidence that an unobserved action truly has value zero.

Every-visit Monte Carlo accumulates each suffix return observed after a pair and divides their sum by its number of visits. First-visit MC uses only its earliest occurrence in each episode. In the three-transition illustration, pair \((2,\text{tram})\) appears twice with returns \(-4,-2\). Every-visit estimate is \(-3\) with count two; first-visit estimate is \(-4\) with count one. Neither single-episode figure is the true action value merely because the arithmetic is exact. The draft, PDF pp.128–129 and 133, distinguishes those sampling rules.

Finite-sample unbiasedness needs special care. Repeated suffixes within an episode are dependent, and a random-count average is not the same as a fixed-count average. Consider Chapter 7's always-stay dice game: each stay pays four dollars and stops with probability \(1/3\). If \(K\) is its geometric episode length, \(\mathbb E K=3\), \(\mathbb E K^2=15\), and true starting value is 12. Its suffix returns are \(4K,4(K-1),\ldots,4\). The one-episode every-visit average is \(2(K+1)\), whose expectation is 8, not 12.

Pooling visits across many independent episodes gives a different estimator. Each episode contributes numerator \(2K(K+1)\) and denominator \(K\). Their expected contributions are 36 and 3. Since these geometric variables have finite moments, independent episode averages converge to those means; the ratio tends to 12. First-visit averaging instead averages \(4K\) once per episode and is unbiased for 12 at every fixed episode count. Thus consistency of an every-visit pooled estimator does not make its finite random-denominator average unbiased. This original counterexample narrows the recording's unbiasedness statement to the individual fixed-policy return claim.

Changing the behavior policy creates another issue: old and new returns can have different expectations. The average then mixes policy versions. A clean evaluation stage freezes a policy while accumulating its returns. Control can deliberately interleave approximate evaluation and improvement, but its evolving table should not be labeled an exact estimate of one fixed \(Q^\pi\) without a tracking argument. The code illustration reports visit means and small-batch differences without such a guarantee.

10. A Q table is useful without being a world model [60:01–66:11]

The recording's discussion corrects an important target: Monte Carlo returns following the current policy estimate \(Q^\pi\), not automatically \(Q^*\). Exact \(Q^\pi\) can still improve a policy. Choose \(\pi_{\mathrm{new}}(s)\in\arg\max_aQ^\pi(s,a)\). Its one-step expected reward plus old-policy continuation is at least \(V^\pi(s)\), because the old action is among the choices.

In a finite discounted MDP this inequality implies policy improvement, not just a better first move. Let \(T^{\pi_{\mathrm{new}}}\) be its expectation operator. It is monotone: if two continuation arrays are ordered coordinatewise, nonnegative probability averaging preserves that order. Starting at \(V^\pi\), the first update is at least \(V^\pi\); monotonicity makes each further update at least its predecessor. Discounted contraction makes the sequence converge to \(V^{\pi_{\mathrm{new}}}\). Therefore \(V^{\pi_{\mathrm{new}}}\ge V^\pi\) in every state. The draft's PDF p.108 states the corresponding improvement criterion; this monotone-operator proof makes the discounted hypotheses explicit.

Noisy estimates can choose the wrong improving action. If true one-step values are 0 and \(-\delta\), estimates that reverse them worsen the one-step policy. Improving and re-evaluating an approximate table is therefore an algorithmic strategy, not a finite-sample monotonic-performance theorem. The source's exploration-phase mean remains cumulative learning performance rather than evidence of a frozen improved value.

A Q table is also not an invertible encoding of the environment. Consider two states with one action each, reward 1 at every decision, and \(\gamma=1/2\). One environment stays in its current state forever; another switches states after every action. Both have \(Q(s,a)=\sum_{j\ge0}(1/2)^j=2\) at both states, but their trajectories differ. Values can determine a preferred action without predicting which observation comes next. A generative world model supports those predictions and counterfactual rollouts; it requires more information than the values alone.

The speaker offers intuitions for learning a policy directly and for returning to richer world models with foundation models. Those are attributed judgments about method choice, not a verified ranking of present systems. Model-free methods avoid explicit transition estimation; model-based methods can reuse a model for multiple planning queries. Their statistical, computational and representation tradeoffs depend on the task. The earlier counterexample establishes an information distinction without claiming universal superiority of either method.

11. SARSA updates before the episode ends [66:11–72:27]

Monte Carlo waits for complete suffix returns. Temporal-difference learning, abbreviated TD, combines an observed immediate reward with an estimate of the continuation. SARSA names the five consecutive trajectory elements state, action, reward, next state and next action. With the old table \(Q_k\), the actual sampled next action \(A_{t+1}\), learning rate \(\alpha_k\in[0,1]\), and terminal flag \(D_{t+1}\), its target and one-coordinate update are

\[Y_k=R_{t+1}+\gamma(1-D_{t+1})Q_k(S_{t+1},A_{t+1}),\qquad Q_{k+1}(S_t,A_t)=(1-\alpha_k)Q_k(S_t,A_t)+\alpha_kY_k.\]

The flag is interpreted numerically as one for terminal and zero otherwise. Operationally the terminal case defines the continuation directly as zero, without asking for an unavailable \(A_{t+1}\). All other table coordinates remain unchanged in this tabular update. The TD error \(Y_k-Q_k(S_t,A_t)\) is the discrepancy driving the step. A target above the old estimate moves it upward; a target equal to it leaves it unchanged. At \(\alpha_k=1\) the new coordinate equals the target, and at zero it remains old.

For a fixed behavior policy \(\mu\), holding the old table fixed before sampling, the conditional mean target is \(\sum_{s'}P(s'\mid s,a)[r(s,a,s')+\gamma\sum_{a'}\mu(a'\mid s')Q_k(s',a')]\), with terminal continuation zero. It is the policy Bellman backup applied to the current estimate. Only when \(Q_k=Q^\mu\) is that mean the true policy value for the pair. The bootstrap can reduce the amount of future reward that must be sampled, while introducing continuation-estimation error. There is no general statement that every TD target is more accurate than a complete return.

For a numerical separation, use old coordinate 3, reward \(-1\), discount \(9/10\), rate \(1/2\), and next-action values 2 and 8. If the next action sampled by behavior is the lower-valued one, \(Y=-1+(9/10)2=4/5\), and the new coordinate is \((1/2)3+(1/2)(4/5)=19/10\). Terminal feedback instead gives target \(-1\) and new coordinate 1. A stored fictitious terminal value 99 would produce target \(881/10\) and new coordinate \(911/20\) if the done mask were ignored. Our table excludes terminal actions and validates the flag against the declared catalogue.

Actual next-action reuse is part of literal trajectory SARSA. Choose the next action, compute the target with it, perform the update, then execute that same selected action. The inspected draft, PDF p.169, Figure 6.9, explicitly assigns \(A\leftarrow A'\); its text defines terminal continuation as zero. The official executable lecture instead samples an action inside feedback and calls action selection again in the outer simulator. Those draws can differ, and an intervening update can change the selection rule. That separate-sample implementation should not be described as the same realized quintuple. Our training loop caches and executes its target action.

The recording calls the update a gradient step. For a frozen scalar target \(y\), the loss \(\tfrac12(q-y)^2\) has derivative \(q-y\), giving exactly the displayed movement. When \(y\) itself uses the same trainable table, holding it fixed is a semi-gradient convention: one does not differentiate through the target. In a one-state example with reward 1 and discount \(1/2\), the residual loss is \(\tfrac12(q-1-q/2)^2\). At \(q=0\), its full derivative is \(-1/2\), whereas the frozen-target derivative is \(-1\). A rate \(1/2\) produces steps to \(1/4\) and \(1/2\), respectively. Calling both the same global Bellman-error gradient would be incorrect.

Sutton's 1988 original paper, PDF pp.7–8, develops incremental updates based on successive predictions; its inspected PDF p.9, Figure 1, illustrates using a well-learned bad state's prediction after a novel state, despite an unusual final win. That example supplies an intuition for reuse of prediction information. It is not a theorem of universal sample efficiency or modern nonlinear-control convergence. The later draft's SARSA convergence paragraph explicitly attributes a result to then-unpublished personal communication; we do not promote it into a separately verified published theorem. Fixed epsilon also keeps exploration in the behavior policy, so an on-policy value includes its future exploratory actions.

12. Q-learning changes the target, not the observed transition [72:27–76:51]

Q-learning uses the same sampled state/action/reward/next-state feedback but replaces the sampled next action by a greedy backup over all admissible next actions:

\[Y_k^*=R_{t+1}+\gamma(1-D_{t+1})\max_{a'\in A(S_{t+1})}Q_k(S_{t+1},a'),\qquad Q_{k+1}(S_t,A_t)=Q_k(S_t,A_t)+\alpha_k[Y_k^*-Q_k(S_t,A_t)].\]

Again, terminal continuation is directly zero rather than the maximum of an empty set. The behavior policy may explore; the target uses a greedy continuation. This target/behavior distinction makes the method off-policy. It does not mean the estimate is independent of how experience is collected: behavior controls which table coordinates are visited and updated. The maximization does not change the successor that actually occurred and does not optimize over nature's outcome.

With the same old coordinate 3, reward \(-1\), discount \(9/10\), rate \(1/2\), and next values 2 and 8, Q-learning chooses bootstrap 8. Its target is \(-1+(9/10)8=31/5\), and its new coordinate is \(23/5\), rather than SARSA's \(19/10\). This difference reflects their continuation targets. If both next values are equal, or behavior selects a maximizing action, the targets coincide. At terminal both targets reduce to the observed reward.

Conditioning on the current pair and the old table, a sampled Q-learning target has mean equal to the optimality Bellman operator applied to \(Q_k\). The finite discounted operator contracts in the supremum norm: the maximum changes by at most the largest coordinate change, and probability averaging multiplies it by at most \(\gamma\). But a noisy, asynchronous update is not the same as applying the full contraction synchronously. Proving its convergence additionally requires repeated coverage and control of the learning rates.

Watkins and Dayan's original 1992 paper, inspected PDF pp.2–4, gives a precise tabular theorem. For a finite controlled Markov task, bounded rewards, \(0<\gamma<1\), finite initial values, repeated visits to every relevant state–action pair, and per-pair step sizes satisfying

\[0\le\alpha_{i,s,a}<1,\qquad \sum_{i=1}^{\infty}\alpha_{i,s,a}=\infty,\qquad \sum_{i=1}^{\infty}\alpha_{i,s,a}^{2}<\infty,\]

the tabular Q estimates converge to \(Q^*\) with probability one under the paper's sampling assumptions. Here \(i\) indexes visits to that pair, not the global episode counter. Its theorem equation was visually inspected because extraction omits the mathematical symbols. A schedule \(\alpha_i=(i+1)^{-0.7}\) stays below one, has divergent sum and convergent square sum by the power-series thresholds. A constant positive rate has divergent square sum; a rate decaying as \((i+1)^{-2}\) has finite total sum and can stop learning too early. Neither satisfies both conditions.

This paragraph states the checked primary theorem rather than pretending to reprove its full action-replay-process argument. Its proof mechanism on PDF pp.4–5 relates updates to a controlled process built from past samples; the detailed appendix is outside our claim-page inspection. Our scalar averaging identities and Bellman contraction explain the roles of averaging and discount but do not replace that stochastic proof. The theorem does not certify a 20-episode demo, fixed learning rate, a nonlinear network, a changing environment or a general \(\gamma=1\) task. The paper discusses absorbing undiscounted extensions, but we do not infer their full guarantee from the discounted theorem.

The original paper uses “episode” for one sampled transition stage, whereas here an episode is a complete terminal rollout. The convergence conditions concern infinitely many pair updates. The draft, PDF pp.171–172, Figure 6.12, independently confirms the max target and terminal convention. The lecture's subclass relationship is a convenient implementation reuse; the mathematical distinction lies in the target, action catalogue and terminal semantics, rather than class inheritance.

A table needs one entry per admissible pair, \(\sum_s|A(s)|\); a dense transition model can need one entry per current state/action/next state. The route is small enough to keep both views. Huge or continuous state spaces cannot be covered by simply creating one dictionary key for every possible observation. Three questions should remain separate when reading a learning result. Did the implementation compute its declared target? Did experience adequately cover the needed decisions? Does the learned policy satisfy the deployment objective under a credible model? A numerical match addresses the first, visit counts inform the second, and frozen evaluation addresses part of the third. None by itself establishes safe exploration, rare-event reliability or correctness under unobserved environmental change.

14. An original finite experiment with explicit contracts

The downloadable chapter program is self-contained and uses only Python's standard library. From this book directory run python programs/chapter08.py. It prints deterministic mechanism checks and separately seeded finite learning fixtures. There are no file, network or device effects. Its known catalogue permits 1–64 named states, at most 16 distinct named actions per state, and empty action rows for terminal states. Route catalogues permit 2–50 locations. These are finite computational bounds, not claims about the largest learnable environment.

Numeric inputs accept integers/floats excluding booleans, convert to finite binary64, and have magnitude at most \(10^{100}\). Probabilities, discount, epsilon and learning rate lie in \([0,1]\); the tram simulator requires failure below one. Intermediate return/target/update results are rounded from exact rational representations of the supplied binary64 values, and must meet the same output bound; a nonzero result rounding to zero is rejected. This controls overflow, cancellation and underflow behavior without making a certified interval-arithmetic claim. Positive per-action exploration probabilities that round to zero are rejected; finite random-number sampling granularity still limits extremely small probabilities.

Sample feedback must use a declared nonterminal state, admissible action and declared successor. Its strict Boolean done must agree with whether the successor has an empty action row. EmpiricalModel copies the action catalogue, retains counts and exact reward sums, and returns rational probabilities/conditional reward means. It accepts at most one million feedback records. Unobserved rows raise ValueError; coverage lists missing pairs. plan_empirical requires all admissible pairs observed, uses \(\gamma<1\), and applies synchronous max backups until a numerical returned-array residual bound meets its tolerance. It raises RuntimeError on an exhausted iteration budget. Its bound measures numerical planning error within the estimated model, not statistical model error or a certified roundoff interval.

suffix_returns accepts 1–10,000 contiguous feedback records ending in exactly one final terminal transition. A truncated nonterminal episode is rejected. monte_carlo reports only observed-pair visit means and counts, with an explicit first/every-visit switch; it does not pretend an unobserved mean exists. initial_q instead constructs the complete admissible table for action selection. td_update validates that exact key set, copies the table, uses a zero terminal target continuation, and requires an actual admissible next action for nonterminal SARSA. Q-learning does not consume such a sampled action. Returned target and table allow direct mechanism checks.

train uses a local seeded random.Random, caches/executes the selected next action, and returns the learned table, pair visits and training returns. Its displayed 2,000-episode runs use \(\gamma=0.9\), \(\epsilon=0.2\) and pair rate \((i+1)^{-0.7}\). The oracle uses the exact rational discount \(9/10\); binary64 training approximates that decimal parameter. This discounted objective differs from literal undiscounted expected minutes. Neither the finite budget nor a positive minimum visit count proves the infinite-coverage condition or SARSA optimality. The 500-episode model-based exploration phase is also seeded, then planning and exploitation are frozen separately.

exact_policy_value is a held-out rational oracle, not data given to the learner. It accepts a complete admissible deterministic policy, or computes the true route optimum by backward self-loop elimination. For discount \(\gamma\), a repeated-tram branch solves \(v=-2+\gamma p v+\gamma(1-p)V(2s)\), yielding \((-2+\gamma(1-p)V(2s))/(1-\gamma p)\); walking gives \(-1+\gamma V(s+1)\). Their maximum satisfies the original optimality equation by the branch argument of Chapter 7. The oracle's discount/failure fractions have denominator at most \(10^{12}\), with failure below one. Evaluating a frozen policy here is exact under the stipulated true model, not a measurement of an actual commuter.

The code below is exactly the downloadable source, and the output is its actual seeded stdout. All three displayed frozen greedy policies happen to attain the same oracle start value in these runs. This observation does not rank sample efficiency, establish optimality for another seed, or prove the learned Q tables equal \(Q^*\). SARSA still trains with exploratory continuation; its extracted greedy policy is a separately evaluated object.

from dataclasses import dataclass
from fractions import Fraction
from math import isfinite
from random import Random


def finite_real(value, name, bound=1e100):
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        raise ValueError(name + " must be an int/float excluding bool")
    try:
        result = float(value)
    except (OverflowError, ValueError) as exc:
        raise ValueError(name + " must be binary64 representable") from exc
    if not isfinite(result) or abs(result) > bound:
        raise ValueError(name + " exceeds the finite documented range")
    return result


def rounded(exact, name):
    result = finite_real(float(exact), name)
    if exact and result == 0:
        raise ValueError(name + " is nonzero but rounds below binary64")
    return result


def unit(value, name):
    value = finite_real(value, name, 1)
    if value < 0:
        raise ValueError(name + " must lie in [0,1]")
    return value


def integer(value, name, low, high):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(f"{name} must be an integer in [{low},{high}]")
    return value


def catalogue(actions):
    if not isinstance(actions, dict):
        raise ValueError("catalogue must be a dict")
    integer(len(actions), "state count", 1, 64)
    fixed = {}
    for state, row in actions.items():
        if not isinstance(state, str) or not state:
            raise ValueError("states must be nonempty strings")
        if not isinstance(row, (tuple, list)) or len(row) > 16:
            raise ValueError("action rows must be tuple/list of length <=16")
        if any(not isinstance(a, str) or not a for a in row) or len(
            set(row)
        ) != len(row):
            raise ValueError("action names must be distinct nonempty strings")
        fixed[state] = tuple(row)
    return fixed


def tram_actions(n=10):
    integer(n, "n", 2, 50)
    return {
        str(s): (
            () if s == n else (("walk", "tram") if 2 * s <= n else ("walk",))
        )
        for s in range(1, n + 1)
    }


@dataclass(frozen=True)
class Sample:
    state: str
    action: str
    reward: float
    next_state: str
    done: bool


def sample_for(actions, sample):
    fixed = catalogue(actions)
    if not isinstance(sample, Sample):
        raise ValueError("feedback must be a Sample")
    if (
        not isinstance(sample.state, str)
        or sample.state not in fixed
        or not isinstance(sample.action, str)
        or sample.action not in fixed[sample.state]
    ):
        raise ValueError(
            "feedback requires a declared nonterminal admissible action"
        )
    if (
        not isinstance(sample.next_state, str)
        or sample.next_state not in fixed
    ):
        raise ValueError("successor must be declared")
    if type(sample.done) is not bool or sample.done != (
        not fixed[sample.next_state]
    ):
        raise ValueError("done must agree with declared terminal successor")
    reward = finite_real(sample.reward, "reward")
    return Sample(
        sample.state, sample.action, reward, sample.next_state, sample.done
    )


def initial_q(actions):
    return {(s, a): 0.0 for s, row in catalogue(actions).items() for a in row}


def q_for(actions, q):
    expected = initial_q(actions)
    if not isinstance(q, dict) or set(q) != set(expected):
        raise ValueError(
            "Q must contain exactly all admissible state-action pairs"
        )
    return {pair: finite_real(q[pair], "Q value") for pair in expected}


def greedy(actions, q, state):
    fixed, q = catalogue(actions), q_for(actions, q)
    if not isinstance(state, str) or state not in fixed or not fixed[state]:
        raise ValueError("greedy requires a declared nonterminal state")
    return max(fixed[state], key=lambda action: q[(state, action)])


def epsilon_probabilities(actions, q, state, epsilon):
    fixed = catalogue(actions)
    best = greedy(fixed, q, state)
    epsilon = unit(epsilon, "epsilon")
    if epsilon and epsilon / len(fixed[state]) == 0:
        raise ValueError(
            "positive per-action exploration probability rounds to zero"
        )
    return {
        a: epsilon / len(fixed[state]) + (1 - epsilon if a == best else 0)
        for a in fixed[state]
    }


def choose(actions, q, state, epsilon, rng):
    if not isinstance(rng, Random):
        raise ValueError("rng must be random.Random")
    probs = epsilon_probabilities(actions, q, state, epsilon)
    draw, cumulative = rng.random(), 0.0
    for action, prob in probs.items():
        cumulative += prob
        if draw < cumulative:
            return action
    return next(reversed(probs))  # finite summation boundary only


class EmpiricalModel:
    def __init__(self, actions):
        self.actions = catalogue(actions)
        self.counts, self.rewards = {}, {}

    def add(self, sample):
        sample = sample_for(self.actions, sample)
        key = (sample.state, sample.action, sample.next_state)
        if sum(self.counts.values()) >= 1000000:
            raise ValueError("feedback budget exceeds 1000000")
        self.counts[key] = self.counts.get(key, 0) + 1
        self.rewards[key] = self.rewards.get(
            key, Fraction()
        ) + Fraction.from_float(sample.reward)

    def row(self, state, action):
        if (
            not isinstance(state, str)
            or state not in self.actions
            or not isinstance(action, str)
            or action not in self.actions[state]
        ):
            raise ValueError("row requires an admissible state-action pair")
        keys = [key for key in self.counts if key[:2] == (state, action)]
        total = sum(self.counts[key] for key in keys)
        if not total:
            raise ValueError(
                ("unobserved action has no empirical distribution")
            )
        return tuple(
            (
                key[2],
                Fraction(self.counts[key], total),
                self.rewards[key] / self.counts[key],
            )
            for key in keys
        )

    def coverage(self):
        return tuple(
            (s, a)
            for s, row in self.actions.items()
            for a in row
            if not any(key[:2] == (s, a) for key in self.counts)
        )


def plan_empirical(model, gamma=0.9, tolerance=1e-9, max_iterations=10000):
    if not isinstance(model, EmpiricalModel) or model.coverage():
        raise ValueError(
            "planning requires feedback for every admissible pair"
        )
    gamma = unit(gamma, "gamma")
    if gamma == 1:
        raise ValueError("generic empirical planning requires discount <1")
    tolerance = finite_real(tolerance, "tolerance", 1e6)
    if tolerance <= 0:
        raise ValueError("planning tolerance must be positive")
    integer(max_iterations, "max_iterations", 1, 10000)
    rows = {
        (s, a): model.row(s, a)
        for s, row in model.actions.items()
        for a in row
    }
    rate = Fraction.from_float(gamma)

    def backup(q):
        result = {}
        for pair, row in rows.items():
            target = Fraction()
            for successor, prob, reward in row:
                continuation = (
                    max(q[(successor, a)] for a in model.actions[successor])
                    if model.actions[successor]
                    else 0.0
                )
                target += prob * (
                    reward + rate * Fraction.from_float(continuation)
                )
            result[pair] = rounded(target, "empirical backup")
        return result

    q = initial_q(model.actions)
    if not q:
        return q, {}, 0, 0.0
    for iteration in range(1, max_iterations + 1):
        q = backup(q)
        checked = backup(q)
        residual = max(abs(checked[pair] - q[pair]) for pair in q)
        bound = finite_real(residual / (1 - gamma), (
            'numerical planning bound'
        ))
        if bound <= tolerance:
            policy = {
                s: greedy(model.actions, q, s)
                for s in model.actions
                if model.actions[s]
            }
            return q, policy, iteration, bound
    raise RuntimeError("empirical planning iteration budget exhausted")


def suffix_returns(actions, episode, gamma):
    gamma = unit(gamma, "gamma")
    if not isinstance(episode, (tuple, list)):
        raise ValueError("episode must be tuple/list")
    integer(len(episode), "episode length", 1, 10000)
    checked = [sample_for(actions, sample) for sample in episode]
    for i, sample in enumerate(checked):
        if sample.done != (i == len(checked) - 1):
            raise ValueError(
                (
                    "only the final feedback may be terminal, and it must "
                    "be terminal"
                )
            )
        if i and checked[i - 1].next_state != sample.state:
            raise ValueError("episode feedback must be contiguous")
    returns, continuation = [0.0] * len(checked), Fraction()
    discount = Fraction.from_float(gamma)
    for i in range(len(checked) - 1, -1, -1):
        continuation = (
            Fraction.from_float(checked[i].reward) + discount * continuation
        )
        returns[i] = rounded(continuation, "suffix return")
    return tuple(returns)


def monte_carlo(actions, episode, gamma, first_visit=False):
    if type(first_visit) is not bool:
        raise ValueError("first_visit must be bool")
    returns = suffix_returns(actions, episode, gamma)
    sums, counts = {}, {}
    for sample, value in zip(episode, returns):
        key = (sample.state, sample.action)
        if first_visit and key in counts:
            continue
        sums[key] = sums.get(key, Fraction()) + Fraction.from_float(value)
        counts[key] = counts.get(key, 0) + 1
    return {
        key: rounded(sums[key] / counts[key], "MC mean") for key in sums
    }, counts


def td_update(actions, q, sample, gamma, alpha, method, next_action=None):
    sample = sample_for(actions, sample)
    gamma, alpha = unit(gamma, "gamma"), unit(alpha, "alpha")
    q = q_for(actions, q)
    if method not in ("sarsa", "q_learning"):
        raise ValueError("method must be sarsa or q_learning")
    if sample.done:
        if next_action is not None:
            raise ValueError("terminal feedback has no next action")
        bootstrap = 0.0
    elif method == "sarsa":
        if (
            not isinstance(next_action, str)
            or next_action not in catalogue(actions)[sample.next_state]
        ):
            raise ValueError(
                "SARSA requires the actual admissible next action"
            )
        bootstrap = q[(sample.next_state, next_action)]
    else:
        if next_action is not None:
            raise ValueError(
                "Q-learning does not consume a sampled next action"
            )
        bootstrap = q[
            (sample.next_state, greedy(actions, q, sample.next_state))
        ]
    target_exact = Fraction.from_float(sample.reward) + Fraction.from_float(
        gamma
    ) * Fraction.from_float(bootstrap)
    target = rounded(target_exact, "TD target")
    pair = (sample.state, sample.action)
    rate = Fraction.from_float(alpha)
    new = rounded(
        (1 - rate) * Fraction.from_float(q[pair]) + rate * target_exact,
        "updated Q",
    )
    q[pair] = new
    return q, target


def tram_step(state, action, rng, n=10, failure=0.4):
    actions = tram_actions(n)
    failure = unit(failure, "failure")
    if failure == 1:
        raise ValueError(
            "this simulator requires positive tram success probability"
        )
    if (
        not isinstance(state, str)
        or state not in actions
        or not isinstance(action, str)
        or action not in actions[state]
        or not isinstance(rng, Random)
    ):
        raise ValueError(
            "step requires admissible state/action and random.Random"
        )
    s = int(state)
    successor = (
        s + 1 if action == (
            'walk'
        ) else (s if rng.random() < failure else 2 * s)
    )
    return Sample(
        state,
        action,
        -1.0 if action == "walk" else -2.0,
        str(successor),
        successor == n,
    )


def train(method, episodes=2000, seed=7, n=10, gamma=0.9, epsilon=0.2):
    if method not in ("sarsa", "q_learning"):
        raise ValueError("method must be sarsa or q_learning")
    integer(episodes, "episodes", 1, 10000)
    integer(seed, "seed", 0, 2**32 - 1)
    gamma, epsilon = unit(gamma, "gamma"), unit(epsilon, "epsilon")
    actions = tram_actions(n)
    q = initial_q(actions)
    visits = {pair: 0 for pair in q}
    rng = Random(seed)
    training_returns = []
    for _ in range(episodes):
        state = "1"
        action = choose(actions, q, state, epsilon, rng)
        episode = []
        for _ in range(10000):
            sample = tram_step(state, action, rng, n)
            episode.append(sample)
            next_action = (
                None
                if sample.done
                else choose(actions, q, sample.next_state, epsilon, rng)
            )
            pair = (state, action)
            visits[pair] += 1
            alpha = (visits[pair] + 1) ** (-0.7)
            q, _ = td_update(
                actions,
                q,
                sample,
                gamma,
                alpha,
                method,
                next_action if method == "sarsa" else None,
            )
            if sample.done:
                training_returns.append(
                    suffix_returns(actions, episode, gamma)[0]
                )
                break
            # The sampled SARSA target action is actually executed next.
            state, action = sample.next_state, next_action
        else:
            raise RuntimeError(
                "training rollout exhausted before terminal arrival"
            )
    return q, visits, tuple(training_returns)


def exact_policy_value(
    policy, n=10, gamma=Fraction(9, 10), failure=Fraction(2, 5)
):
    actions = tram_actions(n)
    if (
        not isinstance(gamma, Fraction)
        or not 0 <= gamma <= 1
        or gamma.denominator > 10**12
        or not isinstance(failure, Fraction)
        or not 0 <= failure < 1
        or failure.denominator > 10**12
    ):
        raise ValueError(
            (
                "oracle requires bounded rational discount and proper "
                "failure probability"
            )
        )
    required = {s for s in actions if actions[s]}
    if policy is not None and (
        not isinstance(policy, dict)
        or set(policy) != required
        or any(
            not isinstance(policy[s], str) or policy[s] not in actions[s]
            for s in required
        )
    ):
        raise ValueError(
            "oracle policy requires every nonterminal admissible action"
        )
    values = {n: Fraction()}
    for s in range(n - 1, 0, -1):
        choices = {"walk": -1 + gamma * values[s + 1]}
        if 2 * s <= n:
            choices["tram"] = (-2 + gamma * (1 - failure) * values[2 * s]) / (
                1 - gamma * failure
            )
        values[s] = (
            max(choices.values())
            if policy is None
            else choices[policy[str(s)]]
        )
    return values

15. Six worked exercises

Exercise 1 — Estimate a row without overwriting rewards

For one state–action pair, observe successor \(u\) twice with rewards 0 and 4, and successor \(v\) once with reward \(-3\). Compute empirical transition probabilities, conditional reward means and expected immediate reward. Explain what remains unknown about an unobserved action and an unobserved successor. Give a check that distinguishes a last-reward implementation from a mean estimator.

Solution

The pair count is three. Thus \(\widehat P(u)=2/3\), \(\widehat P(v)=1/3\). The conditional means are \(\widehat r(u)=(0+4)/2=2\) and \(\widehat r(v)=-3\). Their weighted sum is \((2/3)2+(1/3)(-3)=1/3\), also equal to the pair's overall reward mean \((0+4-3)/3\). This verifies both denominators. Last-reward overwriting would retain 4 for \(u\), producing \((2/3)4-1=5/3\), an incorrect estimate of the observed mean.

No observation of another admissible action means its probability denominator is zero. The algorithm must defer planning, use a declared prior/optimism rule or request more data. It cannot infer that the action is impossible. A zero successor count in an otherwise observed row merely says that successor did not appear in this sample; it does not prove true probability zero. Feed the same transition triple first reward 0 then 4 and verify the returned mean 2 and count 2. Reverse their order: a mean estimator still returns 2, while last-reward storage changes. This check exposes a statistical semantic defect rather than only a numerical rounding issue.

Exercise 2 — First visits, every visits and random denominators

Compute suffixes and first/every-visit estimates for walking 1→2, a failed tram attempt 2→2, and a successful tram attempt 2→4, with artificial terminal 4, at discounts 1 and 1/2. Then derive the one-episode every-visit bias for the always-stay dice game and the limiting pooled ratio across independent episodes.

Solution

At discount 1 the suffixes are \((-5,-4,-2)\). Pair \((1,\text{walk})\) has one return, −5; pair \((2,\text{tram})\) has returns −4 and −2. First-visit MC uses −4, while every-visit MC uses \((-4-2)/2=-3\). At discount 1/2, compute backwards: the last return is −2; the middle is \(-2+(1/2)(-2)=-3\); the first is \(-1+(1/2)(-3)=-5/2\). The tram estimates are −3 for first-visit and \((-3-2)/2=-5/2\) for every-visit. These suffixes end at 4 only under the explicitly artificial episode; applying them as complete returns in the location-10 task would omit later rewards.

For dice, let \(K\) be the number of stays, with stop probability 1/3. Geometric moments give \(\mathbb E K=3\) and \(\operatorname{Var}K=6\), hence \(\mathbb E K^2=15\). The suffix sum is \(4(1+\cdots+K)=2K(K+1)\). Dividing by the random visit count within one episode gives \(2(K+1)\), whose expectation is 8. The true starting return \(4K\) has mean 12. Across \(M\) independent episodes, the pooled estimate is \(\sum_j2K_j(K_j+1)/\sum_jK_j\). The numerator-per-episode mean tends to \(2(15+3)=36\) and the denominator-per-episode mean tends to 3 by the law of large numbers; their ratio tends to 12. Integrability and a nonzero limiting denominator justify this step. Finite-sample unbiasedness of the ratio does not follow. First-visit averaging \(4K_j\) over fixed \(M\) is unbiased because each summand has mean 12.

Exercise 3 — A sampled action and a maximized action are different targets

Use old Q 3, reward−1, discount 9/10, rate 1/2 and next-action values 2 and 8. Compute SARSA when behavior selects 2, Q-learning, and both terminal updates. With epsilon 1/5 and a unique greedy action with value 8, compute the expected SARSA target before observing the next-action draw. When do the two methods' targets coincide?

Solution

SARSA's realized target is \(-1+(9/10)2=4/5\), so its new coordinate is \(3/2+2/5=19/10\). Q-learning's target is \(-1+(9/10)8=31/5\), so new coordinate is \(3/2+31/10=23/5\). Terminal continuation is zero: both have target−1and new coordinate \(3/2-1/2=1\). One must not sample a terminal action or maximize an empty terminal row.

With two actions and epsilon 1/5, low is selected with probability 1/10 and high with probability 9/10. Their mean continuation estimate is \((1/10)2+(9/10)8=37/5\). Expected SARSA target is \(-1+(9/10)(37/5)=283/50=5.66\), less than the max target 31/5=6.2. This expectation conditions on the old table and observed nonterminal successor; it is not a proof of either table's accuracy. The realized targets coincide if the behavior action attains the current maximum, if all next-action estimates tie, if discount is zero, or if the transition is terminal. Exploration can select a maximizer, so an exploratory draw need not force different targets.

Exercise 4 — Repair a trajectory interface

A feedback routine samples next action “walk,” uses it for its SARSA target, updates the table, then the simulator samples “tram” before the next transition. Explain the defect and a complete repair. Separately, test terminal feedback with a stale terminal estimate 99 and reward−1at gamma.9, alpha.5, oldQ3. Distinguish arrival from a time-budget interruption.

Solution

The target uses a next action that is not the next trajectory action. If the table update changes greediness, even the two draws' conditional policies may differ. Repair the loop by selecting \(A_{t+1}\) once at the observed nonterminal successor using the declared behavior rule, computing the old-table target, updating, storing \(A_{t+1}\), and executing that stored action on the next step. A meaningful test supplies a chooser that alternates labels and records calls: after a target action is chosen, the next executed action must equal it, without a second draw in between. A separately sampled target can be studied, but it needs a different declared sampling contract.

If terminal 99 is used, target is \(-1+.9(99)=88.1\) and new Q is \(3+.5(88.1-3)=45.55=911/20\). Correct terminal target is−1and new Q 1. A strict schema can reject terminal Q entries entirely; otherwise a done mask must ignore them. Terminal feedback has no next action. A budget interruption while still in a nonterminal state retains a possible future, so setting done true would change the objective. Either raise an unfinished-episode error, bootstrap under a declared truncation rule, or explicitly add the remaining clock and define a terminal finite horizon. Those are distinct complete specifications.

Exercise 5 — Quantify model error and policy recovery

Assume two finite normalized models share discount gamma < 1 and reward bound \(R_{\max}\). Derive the stated optimal-value perturbation bound from model errors\(d_r,d_P\). Prove the action-gap condition for recovering a unique greedy action. Show why a small seven-transition sample alone does not supply the error premises.

Solution

At true \(V^*\), each action's estimated-minus-true backup has magnitude at most \(d_r+\gamma d_P\|V^*\|\); the max-difference inequality transfers this bound to the optimality operators. Because \(\|V^*\|\le R_{\max}/(1-\gamma)\), call this upper bound \(b=d_r+\gamma d_PR_{\max}/(1-\gamma)\). Insert and subtract the estimated operator applied to true \(V^*\): \(\|\widehat V^*-V^*\|\le\gamma\|\widehat V^*-V^*\|+b\). Rearranging gives \(b/(1-\gamma)\). For action values, the difference is at most \(b+\gamma b/(1-\gamma)=b/(1-\gamma)\), under the same row/reward conditions.

If every action estimate has error at most \(\eta\), a unique best \(a_*\) beats any competitor in the estimated table by at least\(Q^*(s,a_*)-Q^*(s,a)-2\eta\). A true gap greater than twice the error bound therefore preserves the argmax. At equality, an estimated tie is possible; below it, reversal is possible. Counts 2 and 5 give an empirical row 2/7, 5/7 but do not themselves bound its distance to an unknown true row. A confidence procedure would need sampling and coverage assumptions and a stated probability level. In the stipulated oracle model we can compute the actual L1 error 8/35; an unknown-world learner cannot read that oracle distance from its seven observations. Gamma 1 also violates the denominator premise.

Exercise 6 — Design a finite experiment without claiming asymptotic completion

Propose a protocol comparing the four methods on the route. State training/evaluation separation, exploration status, action/terminal handling and visit evidence. Check whether rates constant 0.1,\((i+1)^{-2}\), and\((i+1)^{-0.7}\) meet Watkins–Dayan's per-pair sums. Explain why epsilon_j=1/j and a positive finite minimum visit count are insufficient convergence certificates.

Solution

Declare one state/action catalogue, reward sign, terminal rule and discount before comparing. Retain a true simulator/oracle only for evaluation; learners see feedback. Model-based estimation uses counts and reward means, reports missing pairs and plans only under its declared coverage rule. MC declares fixed behavior during each evaluation batch and first/every-visit choice. SARSA caches its next target action; Q-learning maximizes every admissible next action. Both use zero terminal continuation. Use independent seeds/replications and budgets measured in transitions as well as episodes, because episode lengths differ. Report cumulative training returns separately from a frozen final greedy policy's fresh evaluation, with exploration disabled for that stated evaluation. A second evaluation with exploration retained answers a different question.

For constant 0.1, the step sum diverges but the square sum also diverges. For \((i+1)^{-2}\), both sums converge, so total learning weight can be insufficient. For exponent 0.7, the step sum diverges because 0.7 < 1 and the square sum converges because 1.4 > 1; each rate is below 1. These necessary schedule checks do not by themselves prove all other theorem premises. Index \(i\) counts visits to a particular pair. A rarely visited pair does not get a convergence guarantee merely because another pair has many updates.

If deeper access requires two nongreedy choices, epsilon_j=1/j can produce reach probability1/(4j²), with finite total expected deeper visits. Divergent \(\sum_j\epsilon_j\) then fails to ensure coverage. A finite run with minimum visits 183 shows some observed coverage, not infinitely many future visits. Fixed epsilon also prevents the behavior from becoming purely greedy, so SARSA's exploratory continuation target should not be certified as optimal control by the checked Q-learning theorem. Report exact finite oracle values, estimate errors, visit counts and uncertainty; reserve almost-sure convergence claims for the actual infinite-process hypotheses. Successful finite runs do not demonstrate safe real-world exploration.
